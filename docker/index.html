🚀 Nchan Development Environment

Welcome to your Nchan development environment! This nginx instance is compiled with the Nchan module.

📋 Available Endpoints

POST /pub/{channel_id}
Publish messages to a channel
GET /sub/{channel_id}
Subscribe to a channel (long-polling)
GET|POST /pubsub/{channel_id}
Combined publisher/subscriber endpoint
GET /stats/{channel_id}
Get channel statistics
GET /nchan_stats
Get Nchan status and performance metrics

🧪 Quick Test

Try these commands to test the pub/sub functionality:

1. Publish a message:

curl -X POST -d "Hello World!" http://localhost/pub/test

2. Subscribe to messages:

curl http://localhost/sub/test

3. Check channel stats:

curl http://localhost/stats/test

4. Check Nchan status:

curl http://localhost/nchan_stats

🔧 Development

The source code is mounted at /usr/src/nchan. To rebuild nginx with your changes:

cd /usr/src/nchan && /usr/src/build-nginx.sh && nginx -s reload
